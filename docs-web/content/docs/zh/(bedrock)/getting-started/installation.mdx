Bedrock 支持多种 Python 包管理器。选择最适合你工作流的那一种。

## 前置要求

在安装 Bedrock 之前，请确保你的环境满足以下要求：

- **Python 3.12 或更高版本** —— Bedrock 使用现代 Python 特性，因此要求 `>=3.12`
- **包管理器** —— [uv](https://github.com/astral-sh/uv)（推荐）、pip 或 poetry

<Callout type="info">
我们推荐使用 uv，因为它速度快且内置虚拟环境管理。可通过 `curl -LsSf https://astral.sh/uv/install.sh | sh` 安装。
</Callout>

## 安装 Bedrock

<Tabs items={['uv', 'uv (GitHub)', 'pip', 'poetry']}>
  <Tab value="uv"><CodeBlock code={'uv add bedrock-core'} lang={'bash'} /></Tab>
  <Tab value="uv (GitHub)"><CodeBlock code={'uv add "bedrock-core @ git+https://github.com/maacck/bedrock-py#subdirectory=packages/bedrock"'} lang={'bash'} /></Tab>

  <Tab value="poetry"><CodeBlock code={'poetry add bedrock-core'} lang={'bash'} /></Tab>

## 可选扩展

Bedrock 提供了可选依赖组，以支持更多后端：

<Tabs items={['Redis Cache', 'S3 Storage']}>
  <Tab value="Redis Cache"><CodeBlock code={'uv add bedrock-core[cache-redis]'} lang={'bash'} /></Tab>
  <Tab value="S3 Storage"><CodeBlock code={'uv add bedrock-core[storage-s3]'} lang={'bash'} /></Tab>
</Tabs>

| 扩展 | 包 | 说明 |
|-------|----------|-------------|
| `cache-redis` | `redis>=4.2.0` | 基于 Redis 的分布式缓存 |
| `storage-s3` | `boto3>=1.35.0` | S3 兼容对象存储 |

local storage backend 无需额外依赖；配置 S3 backend 前请先安装 `storage-s3`。

## Bedrock CLI（脚手架工具）

`bedrock-cli` 是 Bedrock 的脚手架配套工具——项目初始化、模块脚手架和代码生成。

<Callout type="info">
  `bedrock-cli` 目前仅支持从 GitHub 安装。PyPI 发布尚在计划中。
</Callout>

<Tabs items={['uv', 'pip']}>
  <Tab value="uv"><CodeBlock code={'uv add "bedrock-cli @ git+https://github.com/maacck/bedrock-py#subdirectory=packages/bedrock-cli"'} lang={'bash'} /></Tab>
  <Tab value="pip"><CodeBlock code={'pip install "git+https://github.com/maacck/bedrock-py#subdirectory=packages/bedrock-cli"'} lang={'bash'} /></Tab>
</Tabs>

完整用法请参见 [Bedrock CLI 文档](/docs/bedrock-cli)。

## 项目初始化

使用标准目录结构创建一个新的 Bedrock 项目：

```bash
mkdir my-project && cd my-project
uv init
uv add bedrock-core
```

然后搭建模块目录结构：

```
my-project/
├── pyproject.toml
├── my_app/
│   └── my_module/
│       ├── __init__.py
│       ├── manifest.yaml
│       ├── entities.py
│       ├── service.py
│       ├── exc.py
│       └── bootstrap.py
└── main.py
```

在 `my_app/my_module/manifest.yaml` 创建一个最小可用的模块清单：

```yaml
title: my_module
description: My first Bedrock module
version: 0.1.0
depends_on: []
```

再编写一个基础的 `main.py` 来启动运行时：

```python
import bedrock

bedrock.setup()

apps = bedrock.apps
print(f"Registry ready with {len(apps.modules)} module(s) loaded")
```

## 验证安装

安装完成后，验证 Bedrock 是否正常工作：

```bash
bedrock -v
```

查看可用的 CLI 命令：

```bash
bedrock --help
```

使用 `app` 命令检查某个模块：

```bash
bedrock app info <module_name>
```

再做一个简单的 Python 验证：

```python
import bedrock

bedrock -v
# Output: Hello from bedrock!
```
